# Yongkang Chengjian Trading — Website V1

A responsive, static English B2B sourcing and contract manufacturing coordination website.

## Preview
Open `index.html` in a browser. Internet connection is optional; Google Fonts may fall back to system fonts.

## Publish
Upload the contents of this folder to a static host such as Vercel, Netlify, or GitHub Pages. Set the project root to this folder. No build command is required.

## RFQ behavior
The RFQ form opens the visitor's configured email application with a pre-filled inquiry to `joya.yu@me.com`. It does **not** send data automatically, upload attachments, or store inquiries. Visitors must attach drawings/photos manually and send the email. Before production deployment, consider integrating a secure form backend and anti-spam controls.

## Publication checklist
- Confirm rights to publish partner-factory photos and any customer-specific product designs.
- Confirm final registered/approved English company name and legal disclosures.
- Review all commercial claims and product-category descriptions with the business operator.
- Obtain a domain and optionally set up a domain-based business email.
- Test RFQ links on mobile and desktop, and test with users without local mail apps.
- Confirm privacy obligations before enabling an online form that collects personal data.

The photos are supplied by the user; they are not stock photography. No confidential PO amounts, customer names, or order numbers are published.
